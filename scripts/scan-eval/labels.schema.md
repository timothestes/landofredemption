# labels.json

`scripts/scan-eval/labels.json` is a JSON array with one object per photo: `{ "file": "IMG_4661.webp", "bucket": "single" | "spread" | "binder" | "none" | …, "tags": ["sleeved", "glare", "binder", "angled", "old-frame", …], "otherGame": false, "cards": [{ "printing": "Captive Priest|FoM|098-Captive-Priest", "setVisible": true, "inFrame": "full" | "partial", "grid": { "row": 1, "col": 1 } }] }`. `file` is the photo's name in `scripts/scan-eval/photos/`; `bucket` groups the summary (buckets starting `single` feed the singles top-1 screen); `otherGame` is true for a photo of another game's cards, where any Matched or Check row is a hard fail, and those cards are not listed. Each card row is the card physically in your hand: `printing` is its `name|set|imgFile` key in `CARDS` (the key `card_prices` uses); `setVisible` is true when you can name the set from the photo itself; `inFrame` is `partial` for a card cut off by the frame or covered, which is never counted as a miss; `grid` is optional, counted from 1 in reading order, top-left to bottom-right, and is used to pair wrong rows with the right card and to score cell match. Every field except `grid` is required: the loader rejects a `printing` of `null` (an unlabeled card: name it, or delete the row if no card is there) and a `setVisible` that is not true or false, lists every unknown key, and names the photos to fix. Extra fields (`status`, `titleRead`, `_draft`, …) are ignored, so the draft file can be edited in place.

To score: `npx tsx scripts/scan-eval/score.ts --labels scripts/scan-eval/labels.json --outputs scripts/scan-eval/outputs/<arm>/ [--photos scripts/scan-eval/photos]`. This scores what the route returned, using the prices the route attached to candidates. To re-score saved reads after a matcher change, add `--rematch --prices <dump.json>`, where the dump is the full `card_prices` table as `{ "name|set|imgFile": price }`. `--rematch` refuses to run without it, because prices taken from returned candidates alone would hide wrong-price picks.
